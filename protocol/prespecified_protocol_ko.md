# 사전등록 — 간호사 × 약물 → 투약 누락

2026-09-03. **측정 전에 쓴다.** 이후 이탈은 전부 11절에 기록한다.
탐색 결과는 `20260831_탐색결과.md`, 관문은 `20260903_관문2종.md`.

---

## 1. 질문

간호사에게는 **관측 특성이 없다** (익명 ID 뿐).
그런데 **투약을 주느냐 마느냐는 간호사가 결정한다** — 용량과 달리 의사 처방의
단순 반영이 아니다.

> **Q1** 개별 간호사를 명시적으로 모델링하면 투약 누락 예측이 개선되는가?
> **Q2** 간호사 x 약물 **잠재**가 간호사 **주효과**를 넘어 기여하는가?

**Q2 가 이 연구의 핵심이다.** CDLD-LoS 는 「의사평균 한 컬럼이 이득의 76%,
잠재가 24% 추가」였다. **여기서 잠재가 주효과 이상이면 LoS 의 재탕이 아니다.**

## 2. 왜 이 설계인가 — 앞선 여섯 사례가 가르쳐준 것

`../20260828_연구자산_총괄.md` 0.5절: **여섯 번 모두 「강한 참조선 위의
상호작용 증분」을 쟀는데, LoS·EdNet 의 주장은 「개체를 넣느냐 빼느냐」였다.**

이 사전등록은 그 교훈을 반영해 **A(개체 없음) → B(주효과) → C(잠재)** 를
나란히 낸다. 개체 순가치는 **C − A** 이고, CDLD 고유 기여는 **C − B** 다.

## 3. 데이터

`emar.csv.gz` (MIMIC-IV v3.1 hosp). 디바이스 선처리는 `도구/build_emar.py`
docstring 참조 (811MB → 슬림 115MB, `NF==12` 검사 필수).

- **`enter_provider_id` 가 채워진 행만** 쓴다 (전체의 14%).
- 필터: 간호사 >= 200건 · 약물 >= 200건 · 셀 >= 5건 (수렴까지 반복)

### 결과변수 — 이진

| 분류 | event_txt |
|---|---|
| **누락 = 1** | `Not Given` · `Hold Dose` · `Not Started` · `Not Applied` |
| **시행 = 0** | `Administered` · `Started` · `Applied` · `Restarted` · `Administered in Other Location` · `Administered Bolus from IV Drip` |
| **지연 → 0 으로** | `Delayed Administered` 등 (**주긴 줬다**) |
| **★제외** | **`Not Given per Sliding Scale`** |

**`Not Given per Sliding Scale`(94만건)을 주분석에서 뺀다.**
인슐린 슬라이딩스케일에서 혈당이 기준에 못 미쳐 안 주는 것은
**프로토콜이 정한 것이지 간호사의 재량이 아니다.**
포함한 판을 민감도로 낸다 (9절).

### ★`emar_detail` 은 쓰지 않는다 — 확인 완료

`20260903_관문2종.md` 1절. `dose_given/dose_due` 의 **98.74%가 정확히 1.0**
이고 `Not Given` 사건은 거기 없다. `complete_dose_not_given` 은 605만 중
Yes 1,009건. **임상적 사유 필드도 없다.**

## 4. 모형

    A : gamma[근무조] + beta[약물] + gamma[진단챕터] + x'theta
    B : A + alpha[간호사]
    C : B + delta[간호사, 약물]        delta = u_i' v_j (랭크 r)

`x` = 연령 · 성별 · 입원유형 · 보험 · **중증도 대리**(진단 개수 ·
입원 중 약물 종수 · 입원 중 투약 사건 수 · ICU 여부 · ICU 재원일수 합)

**중증도 대리는 필수다.** 관문에서 참조선을 거의 안 움직였으나
(0.1801 → 0.1804) **넣지 않은 결과는 보고하지 않는다.**

- 랭크 **[1, 2, 3, 5, 10, 20]** · 릿지 **[1, 10, 1e2, 1e3, 1e4, 1e5, 1e6, 1e7]**
- 가중 **{count, reliability}** — 둘 다 선택 격자에 넣는다
- 선택 = **훈련 셀 내부 4겹 교차검증** (단일 홀드아웃은 항생제 연구에서
  유효표본 10으로 무너졌다)
- ALS 25회, `seed 42`, V 열 단위노름 고정

## 5. 분할

**주판: 환자 단위 5겹.** 같은 `subject_id` 가 겹에 걸치지 않는다.

> **★셀 신호로 판정하지 않는다.** 셀 신호 기반 개체 섞기는 입원 수준 군집이
> 셀에 남아 **위음성**을 낸다 — 이 연구에서 실제로 겪었다
> (셀 신호 순 −0.0009 탈락 vs 표본외 +0.0106 통과).
> `../20260828_연구자산_총괄.md` 1절 ④-라 정정.

**보조판: 시간 분할** (`anchor_year_group`, 2008–2016 훈련 / 2017–2022 검정).

## 6. 지표

**주지표**: `R2 = 1 − SSE/SS_tot` (이진 결과에 선형모형 — 프로그램 내 다른
연구와 비교 가능하게).
**보조지표**: AUC. 함께 보고하되 **판정에 쓰지 않는다.**

**귀무 대조**: **입원 단위로 간호사를 섞는다** (2회).
간호사 정체성만 파괴하고 나머지 구조는 보존한다.
모든 이득은 **섞기 대비 순값**으로 보고한다.

## 7. ★판정 기준 — 측정 전에 못박는다

탐색 결과(총 +0.0173 · 주효과 +0.0068 · 잠재 +0.0105 · 비 1.54)에서
**여유를 두고** 정한다. **사후에 바꾸지 않는다.**

| | 기준 | 못 넘으면 |
|---|---|---|
| **S** 건전성 | 섞기 판에서 잠재 순증분 <= 0 | 구현 오류. 고치고 재실행 |
| **U0** 필수 | 중증도 대리를 참조선에 넣은 상태 | 넣지 않은 결과는 보고하지 않는다 |
| **R** 필수 | **개체 총 순가치 (C−A, 섞기 대비) >= +0.010** | **종료** |
| **Q2** 핵심 | **잠재 순증분 (C−B, 섞기 대비) >= +0.005** | 「주효과만 실재」로 보고 |
| **Q2b** 핵심 | **잠재 순증분 / 주효과 순증분 >= 1.0** | 「LoS 와 같은 구조」로 보고 |

**Q2·Q2b 가 이 연구의 결론이다.** R 은 문턱, S·U0 는 위생.

**Q2 가 떨어져도 발표 가능한 음성이다** — 「간호사 정체성은 예측하나
간호사x약물 조합은 아니다」가 되어 LoS 의 경계를 넓힌다.
**어느 쪽이 나와도 쓸 수 있다.**

## 8. ★먼저 낼 기술 통계 (판정과 무관, 필수)

**`enter_provider_id` 가 정말 간호사인가** — 아직 미확인이다.

- 처방의(`prescriptions.order_provider_id`)와 **18.7% 만 겹친다**,
  입원담당의와는 2.3% (`결과/03_제공자집단.csv`) — 확인됨
- **추가로 낸다**: 이들이 다루는 약물 상위 목록 · 투여 경로 분포 ·
  1인당 담당 환자 수 · 주야 근무 비율
- 약사·사무직이면 약물·경로 분포가 다를 것이다

**결과가 「간호사로 보기 어렵다」면 개체 해석을 바꾼다** —
「투약 기록자」로 쓰고 「간호사」로 쓰지 않는다.

## 10. 미리 적어두는 한계

1. **★`Not Given` 이 오류가 아니다.** 금식·환자 거부·저혈압으로 인한
   **정당한 임상적 보류**가 섞여 있고, `emar_detail` 에 사유 필드가 없어
   **MIMIC 으로는 가릴 수 없다** (관문 확인 완료).
   **「누락(omission)」으로 쓰고 「오류(error)」로 쓰지 않는다.**
2. **제공자 채움률 14%.** event_txt 별로 고르나(Administered 14.7% vs
   Not Given 13.8%) 무작위 결측의 증명은 아니다.
3. **`enter_provider_id` 는 기록자**다. 수행자라는 보장이 없다.
4. **병동 통제가 없다.** hosp 모듈에 careunit 이 없다. ICU 여부만 통제한다.
   `transfers` 를 받으면 개선 가능하다.
5. **배정 교란.** 중증도 대리는 통과했으나 잔여 교란 가능성은 남는다.
   **예측 연구로 쓰고 인과 주장을 하지 않는다.**
6. **방법의 신규성은 주장하지 않는다.** 저랭크 교차 상호작용은 식물육종의
   factor-analytic 모형에서 확립돼 있다. 신규성은 **적용**과
   **투약 누락이라는 결과변수**에 있다.
